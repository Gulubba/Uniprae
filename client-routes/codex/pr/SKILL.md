---
name: pr
description: Route an explicit Premiere Pro request through the installed Uniprae MCP server. Use when the user invokes $pr or asks to control Premiere Pro through Uniprae.
---

Use Uniprae's `ppro_*` tools and the Premiere Pro host only. Check connection and inspect the active sequence before mutation. Complete the user's request from `$ARGUMENTS`; use `ppro_trigger_silencer` for the selected source clip or `ppro_trigger_transcriber` for the active sequence/selected clip when no media path was supplied. Verify the resulting Silenced sequence or caption import.

Use ppro_editor_capabilities and ppro_inspect_timeline to discover current host support and stable clip IDs. Editor tools use zero-based indices. Pass the inspected sequenceId and clipNodeId to mutations; inspect again after structural edits. Prefer cloning the sequence before substantial edits. Use ppro_import_mogrt to create graphics from an existing template on an empty video track, then inspect_mogrt/set_mogrt_value for exposed controls. Inspect component values before setting Motion, Opacity, audio or effect controls. Keyframe times are source-time seconds, not timeline seconds. Verify timeline and properties after edits. Do not claim caption conversion, arbitrary native text creation, universal undo, or full UI parity unless a working capability is verified. Existing AE workflows remain available through $ae.

Treat cleanup as part of completion. Before repeating a failed or uncertain mutation, inspect the current project and timeline so retries do not create duplicate captions, clips, imports, sequences, or effects. If Uniprae or the agent creates an unintended duplicate, partial result, incorrect source range, misplaced clip, or disorganized timeline, repair it immediately when the affected artifacts are safely identifiable. Restore temporary source In/Out marks and preserve the intended edit. Never delete pre-existing user work merely because it looks similar; keep uncertain material as a clearly named backup and make the correct sequence unmistakable. Before reporting success, verify the active sequence name, source duration, track placement, expected item counts, animation/effect state, and project save result. Report any cleanup performed and any remaining backup artifacts.
