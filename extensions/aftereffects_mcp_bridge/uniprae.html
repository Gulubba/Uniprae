Connection

Start Server keeps this Adobe bridge listening while the application and extension stay loaded. The panel remembers your choice and retries listener failures. Stop Server disables automatic recovery.

Each AI client starts its own MCP process. This button controls the Adobe bridge, not the AI client's session. A closed application, unloaded extension, or sleeping computer cannot execute edits.

Clients

Claude Code: /ae or /pr
